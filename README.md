# Cyberpunk Portfolio

A futuristic, cyberpunk-themed portfolio website for digital storytellers and content creators. This portfolio features a dark neon aesthetic with smooth animations and interactive elements.

## 🚀 Features

- **Cyberpunk Theme**
  - Neon color scheme with glowing effects
  - Glitch text animations
  - Interactive particle background
  - Dark/light mode toggle

- **Modern UI Components**
  - Responsive navigation with mobile menu
  - Animated hero section with typewriter effect
  - Interactive cards with hover effects
  - Smooth scrolling and scroll animations
  - Contact form with validation

- **Performance Optimized**
  - Optimized animations using CSS transforms
  - Efficient JavaScript event handling
  - Minimal external dependencies

## 🛠️ Technologies Used

- **Frontend**
  - HTML5, CSS3, JavaScript (ES6+)
  - CSS Variables for theming
  - CSS Grid & Flexbox for layouts
  - CSS Animations & Transitions
  - Font Awesome Icons
  - Google Fonts (Orbitron, Roboto)

- **Libraries**
  - [Particles.js](https://vincentgarreau.com/particles.js/) for interactive background
  - [ScrollReveal](https://scrollrevealjs.org/) for scroll animations

## 🎨 Color Scheme

- Primary: `#05D9E8` (Cyber Blue)

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/cyberpunk-portfolio.git
   cd cyberpunk-portfolio
   ```

2. **Open in browser**
   - Simply open `index.html` in your preferred web browser
   - For development, you can use a local server like Live Server in VS Code

3. **Customization**
   - Update content in `index.html`
   - Modify styles in `css/cyberpunk-theme.css`
   - Add new animations in `css/animations.css`
   - Update interactive elements in `js/cyberpunk.js`
